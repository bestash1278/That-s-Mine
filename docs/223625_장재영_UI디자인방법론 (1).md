# Chapter 02 작성 예시 — 교내 분실물 조회 및 신고 UI

> 모든 행동·발화·수치는 교육용 가상 자료입니다.

## 사용자와 근거

| 항목 | 예시 작성 |
|---|---|
| 서비스 | 교내 분실물 조회 및 신고 서비스 |
| 사용자 | 교내에서 물건을 잃어버리고 분실물 조회를 처음 이용하는 재학생 |
| 맥락 | 수업 사이 모바일로 10분 동안 분실물 확인 |
| 대표 과업 | 잃어버린 물건의 습득 여부와 보관 장소·수령 방법 찾기 |

| 근거 | 내용 | 한계 |
|---|---|---|
| E01 행동 | P01이 강의동과 도서관 안내 데스크의 분실물 문의처를 각각 검색함 | 참여자 1명의 한 장면 |
| E02 행동 | P02가 분실물 공지와 보관 장소 안내를 번갈아 확인하며 연락처를 메모함 | 해당 학교의 실제 공지 체계와 다를 수 있음 |
| E04 발화 | “내 물건이 접수됐는지랑 어디서 찾아가야 하는지 한 번에 알고 싶어요.” | 선호와 실제 행동이 다를 수 있음 |

## 문제문장

> 교내에서 물건을 잃어버린 학생은 짧은 공강에 자신의 물건이 습득되었는지와 어디서 수령할 수 있는지 확인하려 하지만, 분실물 공지와 보관 장소 안내가 여러 경로에 흩어져 있어 여러 곳을 검색하거나 문의하는 데 시간이 걸리고 수령 장소를 바로 파악하지 못한다.

## 방법론 선택

| 방법론 | 판단 |
|---|---|
| HCD | 학생의 실제 분실물 탐색 맥락과 수령 과정에 대한 반복 평가에 적합하므로 중심 접근으로 선택 |
| 디자인 씽킹 | 학생과 보관 담당자의 요구를 파악하고 초기 아이디어를 확장하되 공감만으로 결론 내리지 않음 |
| Lean UX | ‘습득물 목록에 보관 장소를 함께 표시하면 탐색 시간이 줄어든다’는 가설을 빠르게 시험할 때 활용 |

## 3프레임 아이디어

| 프레임 | 사용자 행동 | 시스템 반응 | 가정 |
|---:|---|---|---|
| 1 | 물품 종류·분실 추정 날짜·장소를 선택하고 검색 | 해당 조건의 습득물 목록과 등록일을 표시 | 사용자가 대략적인 분실 정보를 기억하고 입력할 수 있음 |
| 2 | 목록에서 비슷한 물건을 선택해 상세 정보를 확인 | 공개 가능한 물품 특징·보관 상태·보관 장소를 함께 표시 | 공개된 정보만으로도 수령 문의할 후보를 좁힐 수 있음 |
| 3 | 수령 방법을 확인하거나 일치하는 물건이 없으면 분실 신고를 접수 | 수령 장소·문의처·확인 절차를 안내하거나 신고 접수번호와 수정·철회 방법을 표시 | 명확한 안내가 불필요한 문의를 줄이고 신고 접수 여부를 확인하게 함 |

## 검증 가설

> 습득물 목록과 상세 화면에 보관 장소 및 수령 안내를 함께 제공하면, 신규 사용자가 분실물의 보관 장소와 수령 방법을 찾는 시간이 가상 기준 6분에서 3분 이하로 줄어들 것이다.

| 지표 | 목표 | 성격 |
|---|---:|---|
| 분실물 보관 장소·수령 방법 찾기 시간 | 3분 이하 | 가상 목표값 |
| 보관 장소·수령 절차 확인 오류 | 참여자당 1회 이하 | 가상 목표값 |

## 개인 비판 검토

습득물 정보를 자세히 공개하면 타인이 소유자를 사칭하거나 학생증 등의 개인정보가 노출될 수 있다. 따라서 공개 목록에는 이름·학번·연락처와 소유자 확인에 필요한 고유한 특징을 표시하지 않고, 실제 수령 시 담당자가 별도로 소유 여부를 확인하도록 한다.

## 생성형 AI 활용 예시

- 사용: E01~E04만 입력해 문제문장 세 가지와 3프레임 대안을 생성함.
- 채택: `습득물 조회 결과와 보관 장소·수령 안내를 함께 표시`하는 대안.
- 거부: AI가 근거 없이 제안한 `학생증 사진과 모든 개인정보를 공개 목록에 자동 게시` 기능.
- 사람 확인: 각 문장에 근거 ID를 다시 연결하고 실제로 관찰되지 않은 행동과 효과를 단정한 표현을 삭제함.
