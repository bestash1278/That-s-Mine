# 프롬프트 기록 (PROMPT_HISTORY)

개발 과정에서 **사용자가 실제로 입력한 프롬프트**를 시간 순서로 모았다(과제 제출물 ③). 프롬프트 문장은 고치지 않았고(오타 포함), 비밀번호처럼 보이는 값만 `[비공개]`로 가렸다.

> 시각은 한국 시간(KST)이다. Claude 앱 채팅 항목은 채팅 기록의 날짜만 알 수 있어 일부는 시각이 없다. "결과 요약"은 Claude의 답변이 아니라 그 입력으로 무엇이 이루어졌는지를 커밋·문서 기록으로 정리한 것이다. 세션 기록으로 구체 내용을 확인하지 못한 항목은 그렇게 적었다.

## 1. 요약

- 사용자 입력 **52건**(Claude 앱 채팅 16건, Claude Code 대화형 36건). 단계별로 실행한 프롬프트 파일(`prompts/NN.md`)은 각 항목에 접어서 붙였다.
- 자동 실행 스크립트(`run-all.ps1`)로 단계를 돌린 세션 기록(`logs/phase-NN-*`)은 **찾지 못했다**. 이 문서의 Claude Code 항목은 모두 대화형 세션의 입력이다.

## 2. 자료와 한계

- 자료: `docs/prompt-log/claude-app-chat.md`(Claude 앱 채팅에서 입력한 프롬프트), Claude Code 세션 기록 중 **이 프로젝트 폴더**(`~/.claude/projects/C--That-s-Mine`)의 사용자 입력, `prompts/00.md`~`13.md`와 `prompts/_auto-rules.md`·`fix-versions.md`(단계별로 실행한 프롬프트 파일), `PROMPTS.md`(단계 프롬프트 전체 모음), `git log`, `docs/PROGRESS.md`.
- 세션 기록에서는 **사용자가 입력한 텍스트만** 뽑았다. 백그라운드 작업 알림, `/compact`·`/login` 같은 명령, 도구 결과는 제외했다. 다른 폴더(`C--That-s-Mine-prompts`)의 기록은 읽지 않았다.
- Claude 앱 채팅의 프롬프트는 사용자가 정리해 둔 기록(`claude-app-chat.md`)을 그대로 옮겼다. 첨부 파일·붙여넣은 긴 안내문은 그 기록의 표기(괄호 설명)까지만 있다.
- Claude Code의 단계 실행(예: "04.md실행해")은 사용자가 짧게 입력하면 Claude Code가 해당 `prompts/NN.md` 파일을 읽어 수행했다. 그래서 각 항목에 그 단계의 프롬프트 파일을 접어서 붙였다. 파일은 **현재 저장소의 내용**이며, 실행 이후 수정된 것(예: 12단계는 11-22 17:57 채팅에서 보강)은 그 사실을 항목에 적었다.
- 10·11단계는 이번 실행에서 `prompts/10.md`·`11.md`를 읽지 않고 SPEC을 기준으로 구현했다(항목에 표시).
