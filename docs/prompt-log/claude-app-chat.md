# Claude 앱 채팅에서 입력한 프롬프트

Claude Code 밖(Claude 앱 채팅)에서 입력한 프롬프트를 순서대로 모은 기록이다. 13단계에서 `docs/PROMPT_HISTORY.md`를 만들 때 이 파일을 함께 쓴다.

- 프롬프트 문장은 입력한 그대로 옮겼다(오타 포함).
- 날짜는 채팅 기록 기준이다. 정확한 시각을 모르는 항목은 날짜만 적었다.
- 이 채팅의 Claude는 PC에서 명령을 실행할 수 없었다. 그래서 6~9단계는 빌드·테스트 없이 코드만 작성해 `C:\That's Mine`에 저장했고, 빌드 확인은 12단계에서 한다.

## 이후 추가

Claude 앱 채팅이나 다른 도구에서 프롬프트를 더 입력하면 위 표에 이어서 적는다. 비밀값은 적지 않는다.
