# 1단계 — 프로젝트 골격 생성

계획에 따라 프로젝트 골격을 만들어줘.

- git init, 루트 .gitignore (node_modules, build, .gradle, .env, application-local.yml, uploads/ 등)
- backend/: Spring Boot 3.x + Java 17 + Gradle Wrapper. 의존성: web, data-jpa, security, validation, mysql-connector-j, flyway(+flyway-mysql), jjwt, h2(test), lombok(선택)
  - application.yml + application-dev.yml + application-test.yml(H2 MySQL 모드). 비밀값은 ${ENV_VAR} 참조
  - backend/.env.example
- frontend/: Vite + React(JavaScript) + Tailwind + React Router + Axios + lucide-react + Vitest/Testing Library
  - Tailwind 테마에 CLAUDE.md 색상 토큰 등록, Vite dev 프록시 /api → localhost:8080
  - frontend/.env.example (VITE_KAKAO_MAP_KEY, VITE_API_BASE_URL)
- 양쪽 모두 빌드가 통과하는지 실제로 실행해서 확인하고 첫 커밋해줘.
