# 6단계 — 습득물 신고 + 사진 등록

SPEC §10을 구현해줘. 지도 위치 선택은 7단계 컴포넌트를 쓸 것이므로, 지금은 "등록된 교내 건물 선택 + 상세 위치 직접 입력"으로 동작하게 하고 지도 슬롯을 비워둬.

- 섹션: 물품 정보 / 발견 정보 / 발견 위치 / 사진 / 보관 정보
- 과업 B(5분 이내 정확한 입력) 기준으로 설계해: 필수는 종류·물품명·발견 날짜·발견 위치·보관 상태만 두고, 나머지는 "선택" 텍스트로 표시
- 각 필드에 보이는 label + 입력 예시 보조문구(예: 특징 "색상, 브랜드, 크기 · 예: 검은색 장우산, 나무 손잡이")
- 물품 특징 아래에 접힌 상태로 "소유자 확인용 비공개 특징(선택)"을 둔다(→ private_features). "공개되지 않고 관리자만 반환 확인에 사용합니다"라고 안내
- 카테고리 버튼 선택, 발견 날짜 기본값 오늘, 미래 날짜·시간 차단
- 사진: 드래그앤드롭, 모바일 카메라/갤러리(accept, capture), 미리보기, 삭제, 대표 선택, 형식·용량 즉시 피드백, 개인정보 노출 주의 안내
- HANDED_OVER 선택 시 보관 장소 입력 활성화
- "신고 내용 확인" → 상단 오류 요약("2개 항목을 확인해 주세요", 항목 링크) + 필드별 오류 표시 + 첫 오류로 포커스 이동 → 미리보기 → 수정/최종 등록 → 서버 성공 시에만 완료 화면
- 미리보기에서 발견 위치와 보관 위치를 상세 화면과 같은 두 카드 형식으로 보여줘서 혼동을 사전에 확인하게 한다
- 완료 화면: 등록 번호, 등록된 상세 페이지 바로가기, 마이페이지에서 수정·삭제하는 방법 안내
- 서버 오류·네트워크 실패 시 입력 내용을 유지하고 재시도 버튼을 제공한다
- 사진은 선택 항목이다. 시연용 예시 사진 3장을 frontend/public/demo-photos/에 둔다(직접 만든 단순 이미지나 무료 라이선스 이미지, 개인정보 없음)
- 취소 시 입력 내용이 있으면 확인 대화상자
