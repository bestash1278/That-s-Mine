# 10단계 — 반환 신청 + 관리자

SPEC §15, §16을 구현해줘.

- 반환 신청 작성/취소, ownership_description은 신청자 본인과 관리자만 조회
- 관리자 승인 화면에 신청자의 ownership_description과 습득자의 private_features를 나란히 보여줘서 담당자가 비교하게 한다(자동 판정이나 자동 승인은 하지 않음)
- 신청 완료 화면에 "승인은 소유 확인 후 결정되며, 승인 후 보관 장소에서 신분 확인 뒤 수령합니다"와 보관 장소·운영 시간을 안내
- 관리자: 습득물/분실신고/반환신청 목록, 숨김, 정보·발견위치 수정, 보관 위치 지정, 승인/반려(코멘트), 반환 완료, 건물·보관장소 관리
- 상태 전이표를 Service에 정의하고 위반 시 409
- 동시성: 같은 물품에 대해 두 신청을 동시에 승인/완료하는 테스트(스레드 2개)로 하나만 성공함을 검증
- 관리자 페이지는 프론트 라우트 가드 + 서버 권한 모두 적용
