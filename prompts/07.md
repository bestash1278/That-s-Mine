# 7단계 — 지도 기반 조회 및 위치 등록

SPEC §9, §10(지도 위치 등록), §23(지도 키 미설정 처리)을 구현해줘.

- Kakao SDK를 동적 로드하는 훅(useKakaoLoader): 키 없음/로드 실패 시 상태 반환, 앱은 정상 동작
- CampusMap: 캠퍼스 중심은 설정값(환경변수 또는 API)에서, 확대/이동, 현재 위치(권한 거부 시 안내만), 마커 4종 색상 + 범례 + 유형 토글, 클러스터링(services,clusterer 라이브러리), 마커 클릭 팝업/같은 위치 목록, "이 지역에서 다시 검색"
- PC: 좌측 필터+목록 / 우측 지도, 목록↔마커 상호 강조. 모바일: 상단 필터 / 지도 / 하단 접이식 시트
- MapLocationPicker: 클릭 마커 생성, 드래그 수정, 건물 검색/선택, 현재 위치, 선택 좌표 확인 후 폼에 반영. 6단계 신고 폼과 보관 위치에 연결
- 키 미설정 시 대체 UI에 "시연용 위치 선택" 라벨을 명확히 표시
- 지도는 보조 수단이다. 신고 폼에서 지도 없이 "건물 선택 + 상세 위치 입력"만으로 제출이 끝나야 하고, 지도 선택은 좌표를 덧붙이는 선택 기능으로 둔다. 좌표가 없는 물품은 지도에서 건물 좌표로 대체 표시한다
- 이벤트 리스너 cleanup 확인
- 키 없는 상태에서 앱 전체가 정상 빌드·실행되는지 직접 확인
