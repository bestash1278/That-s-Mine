# 8단계 — 회원가입·로그인 (JWT)

SPEC §13, §23을 구현해줘.

- signup(이메일 중복, 비밀번호 규칙), login(JWT 발급), logout, GET/PATCH /users/me
- JwtFilter, SecurityConfig: GET 조회 API·지도 permitAll, 신고/반환/마이페이지 인증 필요, /admin/** ROLE_ADMIN
- 3단계의 임시 허용 TODO 제거, 작성자/관리자만 수정·삭제
- 프론트: AuthContext, 토큰 저장, Axios 인터셉터, ProtectedRoute(로그인 후 원래 페이지 복귀), 헤더 메뉴 전환
- 보안 통합 테스트: 비로그인 401, 일반 사용자 admin 403, 타인 글 수정 403
