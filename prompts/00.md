# 0단계 — 환경 점검 및 계획 (Plan Mode 권장)

CLAUDE.md와 docs/SPEC.md, 그리고 docs/ 안의 223625_장재영_*.md 연구 문서 6개를 모두 읽어줘.

0. 연구 문서의 인사이트(I01~I03), 요구사항 우선순위 1~4, 평가 과업 A/B, 제외 범위를 SPEC 기능과 연결한 추적표를 만들어 docs/DESIGN_RATIONALE.md로 저장해줘. 열은 근거 ID / 사용자 문제 / 대응 기능·화면 / SPEC 섹션 / 검증 방법이고, 근거 없이 SPEC에만 있는 기능은 "명세 요구"로 표시해. 연구 문서 수치는 모두 가상값임을 명시하고, 문서에 없는 사용자 행동이나 발화를 새로 만들지 마.
1. java -version, node -v, npm -v, git --version, MySQL 설치/접속 가능 여부를 확인하고 결과를 표로 알려줘. 없는 도구가 있으면 설치 방법만 안내하고 임의로 설치하지 마.
2. SPEC §26 개발 순서를 기준으로 전체 구현 계획을 세워줘. 각 단계별 생성할 주요 파일, 완료 기준, 검증 명령을 포함해.
3. 명세에서 모호하거나 서로 충돌하는 부분이 있으면 목록으로 정리하고, 네가 택할 기본안을 함께 제시해.
