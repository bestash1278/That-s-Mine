# 무인 자동 실행 규칙

이 세션은 run-all.ps1 스크립트가 사람 없이 단계별로 실행하는 자동 세션이다.

- 사용자에게 질문하지 않는다. 답을 기다릴 사람이 없다. 모호한 부분은 CLAUDE.md와 docs/SPEC.md를 기준으로 가장 합리적인 기본안을 택하고, 그 결정과 이유를 docs/PROGRESS.md의 해당 단계 항목에 기록한다.
- 시작할 때 docs/PROGRESS.md가 있으면 먼저 읽고, 앞 단계에서 무엇을 했는지 파악한 뒤 이어서 작업한다. 앞 단계 결과물을 깨뜨리지 않는다.
- 끝나기 전에 docs/PROGRESS.md 맨 아래에 이 단계 항목을 추가한다:
  `## N단계 — 제목` / 한 일 / 내린 결정 / 실행한 빌드·테스트 명령과 실제 결과 / 남은 문제
- 단계의 완료 기준에 해당하는 빌드·테스트를 실제로 실행한다. 실패하면 원인을 고쳐서 다시 실행한다. 실행하지 않았거나 실패한 것을 성공으로 쓰지 않는다.
- 단계가 끝나면 git으로 커밋한다. 커밋 메시지는 "N단계: 요약" 형식으로 쓴다. .env 등 비밀값 파일은 커밋하지 않는다.
- API 키, DB 비밀번호, JWT 비밀키 같은 실제 값을 만들어 넣지 않는다. 비밀값이 필요한 기능은 플레이스홀더와 H2 테스트 프로필로 검증한다.
- 경로 `C:\That's Mine`에는 작은따옴표와 공백이 있다. 명령에서 경로는 큰따옴표로 감싼다.
- 응답의 맨 마지막 줄은 정확히 다음 둘 중 하나로 끝낸다(스크립트가 이 줄을 읽는다):
  - 완료 기준을 충족하고 빌드·테스트가 통과했으면 `PHASE_RESULT: SUCCESS`
  - 해결하지 못한 빌드 실패, 필수 도구 없음 등으로 다음 단계를 진행하면 안 되면 `PHASE_RESULT: FAILED - 이유`
