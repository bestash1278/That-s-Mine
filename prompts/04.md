# 4단계 — 공통 UI와 메인 페이지

SPEC §5~§7을 구현해줘.

- 공통 컴포넌트: Button, Input, Select, Card, StatusBadge(색+텍스트), LoadingState, ErrorState, EmptyState, Pagination, Modal, Toast
- 레이아웃: PC 상단 내비(활성 메뉴 표시), 모바일 하단 내비(홈/조회/신고/지도/내 정보), 로그인 상태별 메뉴 전환 구조
- 모바일(375px) 우선으로 설계한 뒤 PC로 확장해. 대표 사용 맥락은 공강에 스마트폰으로 확인하는 상황이다
- 메인: 검색 영역(첫 화면에서 스크롤 없이 보이게), 빠른 기능 카드 4개, 카테고리 6개(클릭 시 /items?categoryId=), 최근 습득물 카드(GET /found-items/recent)
- 물품 카드 컴포넌트(ItemCard)는 조회·지도·마이페이지에서 같이 쓴다. 정보 순서를 고정해: 사진 → 물품명 → 카테고리 → "발견: 날짜 · 장소" → 상태 배지 + "보관: 장소명 또는 보관 장소 확인 중"
- 라우터에 11개 페이지 경로를 모두 등록 (미구현 페이지는 "준비 중" 화면)
- npm run build, npm run lint 통과 확인
