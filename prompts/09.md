# 9단계 — 분실 신고 + 마이페이지

SPEC §11, §14를 구현해줘.

- 분실 신고 CRUD + /lost-reports/map, 분실 기간(lost_date~lost_end_date), 대표 추정 위치 + 추가 설명, MapLocationPicker 재사용
- 조회 결과 없음 화면에서 넘어온 쿼리(keyword, categoryId, 날짜)를 폼 초기값으로 채운다
- 완료 화면에 접수 번호(예: LR-000123)와 "마이페이지에서 수정·철회할 수 있습니다" 안내, 그리고 바로 계산된 유사 습득물 미리보기(11단계 후 연결)
- 마이페이지의 내 분실 신고 카드에 "유사 습득물 N건" 표시(화면 내 표시만 하고 푸시·이메일 알림은 범위 밖)
- 마이페이지: 회원정보 수정, 내 습득물/분실신고/반환신청 탭, 상태 배지
- 상태별 수정·삭제 제어: RETURN_PENDING/RETURNED 습득물, 진행 중 반환 신청이 있는 건은 수정·삭제 제한(서버 검증 + UI에서 이유 표시)
- 삭제는 soft delete, 삭제 전 확인 대화상자
